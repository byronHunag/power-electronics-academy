# 课程内容维护指南

## 文件关系

- `index.html`：页面结构、样式、搜索、章节导航、课程详情和本地课程编辑器。
- `content.js`：全部课程数据。网站通过普通script标签加载，不需要构建步骤。
- `.github/workflows/deploy-pages.yml`：提交到main后自动发布GitHub Pages。

## 课程数据字段

每门课程是一个对象，至少包含：

```js
{
  id: "llc-13",              // 唯一ID，建议模块-两位课号
  module: "llc",             // pfc / mag / llc / flyback
  number: 13,
  title: "课程标题",
  status: "full",
  summary: "核心原理",
  formula: ["公式1", "公式2"],
  waveform: "关键波形、正常形态和异常判据",
  selection: "设计计算、器件选型和最坏工况",
  debug: "调试步骤、测量节点和故障判断",
  mistakes: "常见错误及其后果",
  interfaces: "与前级、后级和系统控制的关系",
  questions: ["复习题1", "复习题2", "复习题3"],
  source_note: "适用条件、假设和资料来源说明",
  application: "本课应用场景（可选，默认按模块显示）",
  derivation: "推导、因果关系与适用边界（可用换行分段）",
  worked_example: "计算假设、代入、结果及边界",
  bench_steps: ["实操步骤1", "实操步骤2", "实操步骤3"],
  answers: ["题1参考答案", "题2参考答案", "题3参考答案"],
  references: [               // 可选，仅渲染有效HTTPS链接
    { title: "厂商原始资料名称", url: "https://www.ti.com/..." }
  ]
}
```

## 发布步骤

1. 修改或新增 `content.js` 中的课程对象。
2. 保持每个 `id` 唯一，`module` 必须属于四个既定模块。
3. 如扩展课程规划，同步更新 `modules[].total`；主干已完成时 `next` 设为 `null`。
4. 在 `updates` 开头新增日期、标题、摘要和 `lesson_id`，首页会链接到该课；按需更新 `version` 和 `updated_at`。
5. 本地打开 `index.html` 检查课程、公式、搜索和章节导航。
6. 提交 `content.js` 到 `main`，查看GitHub Actions部署结果。

## 工程内容审核清单

- 公式注明适用拓扑、工作模式和近似条件。
- 波形注明测量参考点、探头类型和预期工作状态。
- 计算覆盖最低/最高输入、轻载/满载、温度和器件公差。
- 选型核对耐压、电流、损耗、热阻、降额和安规。
- 故障分析先区分真实电流/电压异常与探头接法、带宽、接地引入的测量假象。
- 市电和高压母线操作必须列出隔离、放电和防触电要求。

## 阅读与编辑约定

- 正文字段可使用换行分段；内容统一按纯文本转义，不在课程字段中嵌入HTML或脚本。
- `references` 保留资料标题和原始HTTPS地址，链接在新标签打开；优先采用厂商数据手册和应用说明。
- 新增课程编辑器只增加未占用课次，关闭按钮不会提交；修订已有课程请直接编辑数据文件，并保留应用场景及资料字段。
- 示例数值须注明假设。没有用户样机原始数据时，测试项目写为计划/待测，不得写成已通过。
- 800W是平台称谓；当前60～93V、2～8A规格最大工作点为744W。65W反激输入范围是176～276Vac，不能等同通用输入范围。



## 深度讲义检查

- 参考答案数量须与复习题一一对应；不得以重复的通用答案替代本课题目。
- 公式列出变量、单位、适用工作模式和近似条件；数值例需先检查周期/能量/应力自洽。
- 磁通Bpk与ΔBpp、电感开路值与等效Lm、串联电流与负载反射电流必须区分。
- 共用拓扑示意要标明用途；不得写成该课程/样机的实测图。
